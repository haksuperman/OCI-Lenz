# 연결 구조를 보존하는 여백 축소
입력: AGENTS.md, HARNESS/PRD/ARCHITECTURE/ADR, Draw.io/OCI 스킬,
composition.py, quality.py, ai.py, visual_review.py, 기존 연결선 검증 결과.
인터페이스: 실제 렌더링 경로 + alias 배치 → 경계 여백 수치/안전한 축소 지침
→ AI 수정 geometry → 원래 관계와 연결선 가독성 보호 검증 → native XML/PNG.
범위: 프레임 바깥쪽의 불필요한 여백을 실제 자식/선 경로와 구분하고
구체적인 축소 범위를 제공한다. 화살표 통로/행 분기/측면 버스/진입부 유지.
지역 프레임 축소 시 상단 제목도 일정 간격으로 따라가 외부 빈 띠를 남기지 않는다.
AC: 안전한 경계 지침과 무변경/결정성/제목·꺾임 보존/퇴행 거부 회귀,
전체 테스트 및 가상 데이터의 실제 AI 수정·PNG·정확한 재생성 검증.
금지: API 부모/관계 변경, 임의 서비스 추론, 고객 데이터 공개, 단순 간격
일괄 축소, 기존 배치의 조용한 자동 재배치, 자동 commit/push, phase 상태 조작.
