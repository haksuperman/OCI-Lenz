# 검증 근거

- 연결된 항목의 72px 통로, 네트워크 96px 통로, 행/측면 공통 분기,
  독립 도착점, 24px 단말 구간, 제목 회피, 수평 회전, 결정성,
  실제 가독성 개선에 한정한 면적 증가 수용을 검증하는 회귀 18개를 추가했다.
- 전체 410개 테스트가 OCI SDK 2.192.0 및 최소 지원 2.191.0에서 통과했다.
  하네스 check와 git diff --check도 통과했다.
- 가상 nlb-backends 및 fanout을 공통 AI 규칙으로 생성하고 최종 라우터로
  동일 layout을 재생했다. 네이티브 XML 검증, 바이트 단위 정확한 재생성,
  PNG 전체 payload/CRC 검증 통과. 각각 1384×942, 1966×1239 PNG를 확인했다.
- 두 가상 사례 모두 화살촉 혼잡, 짧은 단말, 연결 통로 부족, 분기 행 방해,
  리소스/제목 침범, 선 겹침, 대각선, 모호한 교차가 0이다.
  PNG에서 공식 아이콘과 네이티브 라벨, 공통 T 분기와 분리된 도착점을 확인했다.
- 전체 시각 품질 통과로 보고하지 않는다. 원래 AI 시각 검토 및 최종 코드
  품질은 여백 관련 needs_review이며, replay 시각 검토는 재사용으로 건너뛴다.
  빈 공간을 감추려고 판정 기준이나 결과를 통과로 변경하지 않았다.
- 실제 로컬 스냅샷의 이전 배치와 부모/관계/리소스 위치를 그대로 유지한
  대조에서 화살촉 혼잡 2→0, 짧은 단말 25→0, 리소스/제목 침범 0을 확인했다.
  기존 위치의 통로 부족 16.708333 및 분기 행 방해 3은 그대로 측정된다.
  새 위치 생성 규칙과 고정 위치 재생의 효과를 구분한다. 실제 OCI 재조회 없음.
- 일반 패키지 설치 후 저장소 밖 isolated Python에서 site-packages의
  branch_routes/routing 모듈과 최종 소스의 바이트 일치를 확인했다.
- 고객사 그림과 스냅샷, 상세 비교 자료는 저장소 밖 private 경로에 유지한다.
  자동 commit/push 없음. phase 상태는 실행기가 관리한다.
