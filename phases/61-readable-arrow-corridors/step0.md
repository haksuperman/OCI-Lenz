# 앞으로 생성하는 모든 구성도의 화살표 가독성
입력: AGENTS.md, HARNESS/PRD/ARCHITECTURE/ADR/USAGE, connector_rules.py,
routing.py, composition.py, quality.py, ai.py, visual_review.py, 기존 스킬·테스트.
인터페이스: 실제 관계 → alias-only 통로/분기 규칙 → AI 위치/일반 직각 라우터
→ 동일 모델의 네이티브 Draw.io/PNG → 코드 품질 및 시각 검토.
범위: 연결된 항목의 72px 통로, 독립 화살촉 분리·정상 진입 구간, 같은 출발점의
행 분기/다중 행 측면 버스, 분기 행 간격 부족/단말 혼잡 측정. 공간 증가를 허용해
실제로 연결 가독성이 좋아진 수정안을 채택하되 침범·모호한 교차는 허용하지 않는다.
AC: index.json의 서비스 독립/상대 배치 변화/같은 출발점·다른 출발점/결정성/
원본 그래프 보존/큰 캔버스의 조건부 수용 회귀, 전체 테스트, 가상 PNG 시각 검사.
금지: 고객사별 좌표 하드코딩, 스냅샷 관계/부모 변경·선 숨김, 글자/리소스 침범,
단순 크기 증가를 개선으로 위장, 고객사 파일/원문 응답 공개, 자동 commit/push,
품질 판정을 통과로 조작. 기존 작업 트리 변경을 보존하고 상태는 실행기가 관리.
