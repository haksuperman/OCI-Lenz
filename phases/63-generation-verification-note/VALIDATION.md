# 검증 근거

- 5개 회귀: AI provider가 확인된 배치의 모든 페이지 안내, AI 미사용 진단 구분,
  리소스/연결선/모델 입력 불변, 안내 잘림·침범 거부와 레거시 XML 호환,
  좁은 빈 페이지의 줄바꿈을 검증했다. 기존 자원·부모 오류를 먼저 검증하며
  안내 검사가 원래 오류를 가리지 않도록 기존 VPN 회귀도 유지했다.
- 최종 전체 428개 테스트가 SDK 2.192.0 및 최소 지원 2.191.0에서 통과했다.
  하네스 구조 검사와 git diff --check 통과. phase 상태는 실행기가 관리한다.
- 가상 fanout의 기존 AI 배치 재생 및 빈 인벤토리의 no-ai 공개 CLI 생성으로
  실제 Draw.io/PNG를 확인했다. AI 재호출이나 실제 OCI 조회는 수행하지 않았다.
  XML 검증, 동일 snapshot/layout의 정확한 재생성, 모든 PNG payload/CRC 통과.
- fanout의 architecture.png(1950×1171) 하단에 AI 활용·실제 OCI 리소스/설정
  대조·검증 후 사용 안내가 표시되고, 좁은 빈 그림(274×280)은 자동 생성으로
  구분되어 잘림 없이 줄바꿈된다. 정보 페이지에도 같은 구분의 안내가 포함된다.
- fanout XML에서 새 안내만 제거하면 이전 문서와 정확히 일치한다.
  안내는 별도의 편집 가능한 native 텍스트이며 자원/프레임/선 geometry 불변.
- 일반 패키지 설치 후 저장소 밖 isolated Python에서 최종 렌더러 소스 일치를
  확인했다. 고객사 정보·이미지·실제 스냅샷·키/프로필은 변경에 포함하지 않는다.
  가상 검증 산출물은 저장소 밖에 보관한다. 사용자가 머지하며 자동 머지는 없다.
