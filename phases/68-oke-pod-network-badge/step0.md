# OKE Pod Subnet 역할 배지
입력: AGENTS.md, 프로젝트 문서, OCI/Draw.io 스킬, OKE 네트워크 구현,
기존 실제 스냅샷/배치(저장소 밖), header/routing/quality/네이티브 검증.
인터페이스: 확인된 Pod Subnet 참조 → 기존 제목의 역할 행에 native 배지와
공식 OKE 아이콘 → 동일 관계/배치의 Draw.io/PNG. 새로운 OCI 리소스는 아니다.
범위: Subnet 이름/CIDR·부모 보존, 독립 편집 가능한 배지, 라우팅/품질 장애물,
기존 헤더 예약과 저장 배치 호환, 가상 및 기존 실제 스냅샷 재렌더링.
AC: 근거 없는 배지 없음/배치·관계 불변/공식 아이콘/클리핑·선 회피/익명화/
전체 테스트, 실제 PNG 점검과 정확한 재생성.
금지: 고객 자료 공개, 추가 OCI 조회, 모델 재배치 강제/고객별 좌표,
새 Pod/Pool 리소스나 통신선 추측, 자동 commit/push.
