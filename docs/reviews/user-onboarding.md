## 개인 환경 의존성

고정 고객사 프로필·컴파트먼트·리전·로컬 사용자 경로를 실행 기본값으로
사용하는 코드는 찾지 못했다. 공식 샘플과 기본 참고 이미지는 가상 데이터다.
Codex와 OpenAI의 사용자 모델·연결은 로컬 설정이나 명시적 옵션을 사용한다.
Draw.io 표준 설치 위치는 플랫폼 기본 경로이며 특정 사용자 홈을 고정하지
않는다. per-user macOS 설치 위치를 추가로 지원하고 doctor/export가 같은
탐색 함수를 사용한다. 프로필·키 파일·다른 사람의 로그인 상태를 복사하지 않는다.

## 작성자 정보 공개 방침

Git의 작성자 이름·이메일은 기여 기록에 사용된다. 개발자가 공개를 선택한
이름과 이메일을 유지하는 방식과 GitHub noreply 주소를 사용하는 방식 모두
지원된다. noreply 사용 여부는 개발자의 선택이며 기여 이력을 숨기는 기능은
아니다. 이 프로젝트에서는 본인이 허용한 작성자 정보를 유지한다.

향후 CLI 커밋에는 본인이 선택한 GitHub 연결 이메일이나 noreply 주소를
사용한다. GitHub 웹 merge의 이메일 설정과 로컬 Git 설정은 각각 확인한다.
설정 변경은 과거 커밋을 바꾸지 않는다.
[GitHub 공식 문서](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address)

보고하고 처리한다.
